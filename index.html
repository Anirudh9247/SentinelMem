Multi-Signal Trust Formula

TrustScore = (0.35 * S_drift) + (0.15 * S_temp) + (0.30 * S_prov) + (0.20 * S_cred)

  • • Score ≥ 0.75 → ALLOW (Pass in demo result)
  • • 0.50 ≤ Score < 0.75 → FLAG (Mark passed with annotation)
  • • 0.30 ≤ Score < 0.50 → QUARANTINE (Mark not passed; no persistent store)
  • • Score < 0.30 → BLOCK (Mark not passed)
