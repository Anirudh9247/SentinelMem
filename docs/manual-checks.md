## Seed protocol decision

Keep the fixed baseline as the stable control and use the opt-in seeded query-variant sampler for wording-sensitivity runs. The sampler selects one query from each of four intent families using a stable SHA-256 ranking; it does not modify the corpus or the existing fixed baseline artifacts. The 20-seed matrix is a descriptive protocol check over 16 hand-authored variants. Expand and validate the query pool before reporting inferential confidence intervals or security-efficacy claims.
